# 拾语视觉基线

这份基线是新增页面和组件的验收契约。它记录当前产品的视觉方向、状态表现和固定视口，评审截图差异时优先比较布局、层级和状态，不追求逐像素冻结动态文案。

## 视觉方向

默认的青瓷绿画布衬托象牙色结果区，朱红色用于录音按钮与结果标题旁的短线。经典黑白沿用中性画布和石墨色录音键。深梅紫方案以杏桃色突出录音和整理结果。

主窗口、悬浮球、偏好设置及其下拉菜单使用同一配色。青瓷为浅色，梅紫为深色，经典黑白可选择浅色、深色或跟随系统。浮动窗口只在胶囊内部着色，四周保持透明。

颜色、间距、圆角与布局变量集中在 [`frontend/src/styles/theme.css`](../frontend/src/styles/theme.css)，全局 reset 与平台窗口层变量在 [`frontend/src/styles/global.css`](../frontend/src/styles/global.css)。组件样式一律是就近的 `.module.css`。

| 用途 | Token | 说明 |
| --- | --- | --- |
| 应用画布 | `--app-canvas` | `--gray-2`，与内容面板区分 |

| 次级/弱化文字 | `--app-ink-soft` / `--app-ink-faint` | `--gray-11` / `--gray-9` |
| 边界 | `--app-border` / `--app-border-strong` | `--gray-a5` / `--gray-a7` |
| 主按钮 | Radix `Button color="gray" highContrast` | 浅色近黑、深色近白 |

| 状态色 | `--app-danger` / `--app-success` | `--red-9` / `--jade-9` |
| 圆角 | `--app-radius-xs` / `sm` / `md` / `lg` | 5 / 7 / 10 / 14px；Radix 控件统一 8px，弹窗 16px |
| 卡片落影 | `--app-shadow-card` | 1px 的 `--black-a2`，只用来把卡片与画布分开，深色下几乎不可见 |
| 窗口层 | `--app-header-height`、`--app-titlebar-inset` | Windows/Linux 标题栏随宽度在 42–66px 之间调整。macOS 保持 36px，并给交通灯留出 78px |
| 内容宽度 | `--app-content-max` | 约束列表页宽度，记录页的两栏均分可用空间 |

字体跟随宿主系统，不加载网络字体；正文 13px（`scaling="90%"` 下的 size 2），说明 11.5–12px，页面标题 22px。

## 品牌标记与图标

品牌标记是「声纹成字」：左边三根竖条是声纹，右边两条横线是整理后的文字，最高的一根竖条与两条横线共用上下基线。从左往右读就是产品的动作——说话，然后变成文字。

权威几何只有一份：[build/icons/app-icon.svg](../build/icons/app-icon.svg)。应用图标、favicon 与 DMG 文件图标（反相配色）都由它与同目录的变体 SVG 渲染：`common:generate:brand` 出位图，`common:generate:icons` 再把位图转成 `.icns` / `.ico`。**改图标只改 SVG，不要直接改 PNG、ICO、ICNS。**

| 用途 | 源 | 规则 |
| --- | --- | --- |
| 应用图标（macOS / Windows / Linux） | `build/icons/app-icon.svg` | 石墨砖 `#202020`（Radix gray-12 浅色档）+ 白色声纹 + 靛蓝文字线；砖外边距 100、圆角 184，内容 824² |
| DMG 文件图标 | `build/icons/dmg-file.svg` | 反相配色：白砖 + 石墨标记，与应用图标一眼分开（文件不等于应用） |
| DMG 窗口背景 | `build/icons/dmg-background.svg` | 中性灰渐变，不出现任何第三方标识 |
| favicon | 由 `app-icon.svg` 渲染成 64² | 自带砖底，标签页在明暗两套系统外观下都可见 |
| 应用内标记 | [frontend/src/components/BrandMark.tsx](../frontend/src/components/BrandMark.tsx) | 小尺寸精简版：两柱两线、`currentColor` 单色，随主题翻转 |

小尺寸规则：应用内标记用 24 网格，柱宽 = 线高 = 3.4，竖组间距 2.6，14–18px 下仍能读成「左竖右横」。五元素全量版在 32px 以上各自清楚，16px 帧（Windows ico）只保留砖的剪影与声纹节奏；这是刻意取舍，不另做第二套小尺寸艺术稿，两套稿才是不一致的根源。

对比度按 WCAG 对石墨砖 `#202020` 实算：白色 16.3:1、靛蓝 `#5472E4` 3.8:1，都高于非文本图形 3:1 的下限。应用内标记不写死颜色，浅色主题继承 `--app-ink`，深色主题自动变近白。

## 固定视口

| 视图 | 视口 | 期望结果 |
| --- | --- | --- |
| 桌面主视图 | 1280 × 820 | 顶部是标题栏与图标工具栏，原文和整理结果并排，结果标题右侧是复制按钮 |
| 窄桌面 | 1024 × 768 | 两栏正文完整可见，长文本在栏内换行 |
| 移动端 | 390 × 844 | 编辑区纵向排列，设置表单单列，工具栏可用 |
| 主窗口最小 | 640 × 640 | 图标、列标题和输入框可达，界面没有横向滚动 |
| 最小宽度 | 320 × 任意高度 | 标题、按钮和输入框不被裁切，不出现横向滚动 |

主窗口默认大小为 1000 × 820，最小为 640 × 640。桌面正文区使用中间分隔线，窄屏时改为上下阅读。

Chromium 截图覆盖应用内容层，原生窗口按钮和浮动窗口需在桌面应用中验收。

## 组件状态

| 组件 | 默认 | 交互/工作中 | 空/禁用 |
| --- | --- | --- | --- |
| 录音按钮 | 使用当前配色的主操作色 | 录音时切换为停止图标，录音或处理期间可取消 | 请求麦克风和等待模型时显示相应状态 |
| 原文 | 可编辑文本区 | 流式识别文字逐步写入，可基于修改后的原文重新整理 | 空白时保留编辑区域 |
| 整理结果 | 主题色短线、栏标题、复制图标 | 显示整理正文、列表和段落，复制时取完整文本 | 缺少结果时禁用复制 |
| 预设编辑页 | 左侧预设列表 + 右侧名称与提示词编辑，当前生效项高亮 | 新建、复制、设为当前、删除（AlertDialog 二次确认）；只剩一个时删除禁用 | 名称或提示词为空时就地提示，不隐藏保存按钮 |
| 设置弹窗 | 使用当前配色的 Radix Dialog 与标签页 | 选择其他配色后同步预览，关闭后保留选择 | 模型、快捷键等设置使用各自的保存操作 |
| Toast | 底部居中，1px 边框带阴影 | 成功 2.6 秒、失败 5 秒后自动消失 | — |
| 调用概要条 | 一行 chip：接口类型、模型、音频时长、耗时、实时倍率、token | 点「详情」展开字段网格与原始 usage（Collapsible） | 没有调用时显示「等待调用」 |
| 调用记录页 | 每次调用一行，成功绿色勾选、失败红色警示 | 展开行显示与概要条相同的详情；顶部汇总成功/失败/总耗时/总 token | 无调用时显示空状态 |
| 应用标题栏 | 左侧品牌、右侧窗口按钮，工具栏紧随其下 | 拖动标题栏可移动窗口，Windows/Linux 双击空白处可最大化或还原 | 浮动模式隐藏标题栏 |

录音、处理中和完成等状态用图形或可读提示区分。系统开启减少动态效果时，按钮和转场遵循相应偏好。

## 桌面专属状态

主窗口使用顶端工具栏和并排编辑区。后台空闲时浮动窗口隐藏，通知出现在小球里。录音时小球展开为横向胶囊，只显示随声音变化的波形和停止图标。整理完成后原位显示可复制的全文，5 秒后收起，完整结果也可在历史记录中查看。[浮动窗口交互](desktop-interaction.md)

## 人工验收清单

1. 桌面视图的原文与结果之间有一条细分隔线，页面没有横向滚动。
2. 开始录音、录音中、结束录音和处理中四个阶段都能通过文案及图标辨认。
3. 原文可编辑，结果的段落和编号清晰，复制图标始终位于结果标题旁。
4. 用 Tab 可到达录音、新建、历史、设置、编辑区及其可用操作，图标按钮有可访问名称。
5. 390px 宽度下可以依次阅读原文和结果，设置表单变为单列。
6. 开启「减少动态效果」后，录音状态仍可辨认，界面切换不依赖动画。
7. 调用概要条与调用记录页在 1280px 和 390px 下都不横向溢出；展开后的详情网格按可用宽度自动换列。
8. 浅色与深色两套下，文字与背景的对比度都足够，没有任何色块在切换后糊成一片。
9. macOS 的原生交通灯与拾语标记位于同一行，按钮之间没有遮挡。
10. Windows 11 顶带右端显示窗口按钮，双击顶带空白处可最大化和还原。点击关闭按钮时按用户设置询问、进入后台或退出。
11. 浮动模式没有标题栏、交通灯或方形底色；右键弹出的是系统原生菜单；展开后交通灯和完整画布恢复。
12. 在设置里切换整理预设后，重新整理使用新预设，已完成的结果仍能复制。
13. 在后台按录音快捷键后显示开启麦克风的进度图标，麦克风就绪后显示停止图标。录音超过 5 秒时胶囊持续可见，整理结果出现 5 秒后自动隐藏。
14. 工具栏能打开历史、设置和调用记录，并可回到当前草稿。
15. 工具栏与悬浮球的右键菜单都可以取消录音和转写。取消后回到待录音状态，已取消的片段不写入历史。
16. 标题栏的「两柱两线」标记随主题使用对应文字色。macOS 程序坞与 Windows 系统托盘沿用拾语应用图标。

## 生成截图

不引入额外浏览器依赖；已安装 Chromium 或 Google Chrome 的环境可直接运行：

```bash
cd frontend
./scripts/capture-visual-baseline.sh
```

脚本先执行 Vite 构建，再把 `docs/visual-baseline/` 作为唯一输出目录，生成 `idle-1280.png` 和 `idle-390.png`。可通过 `CHROMIUM_BIN=/path/to/chromium` 指定浏览器，或把输出目录作为第一个参数传入。脚本会为 headless 浏览器使用临时用户目录；Edge 等 Chromium 分支会把小窗口钳制到约 492px，生成 390px 截图时请使用 Chromium/Chrome。

在 1280px 和 390px 宽度下，`idle-1280.png` 与 `idle-390.png` 记录默认青瓷配色。切换为深梅紫后，分别保存为 `idle-1280-dark.png` 和 `idle-390-dark.png`。浏览器预览支持 `?platform=windows`，可用于检查 Windows 标题栏与窗口布局。
